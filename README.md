## 📖 项目简介

Go 是由 Google 主导开发的开源编程语言,语法简洁、并发原生支持、编译速度快,广泛用于云原生基础设施、后端服务和命令行工具的开发。本仓库是 Go 语言官方源代码仓库(github.com/golang/go 为 go.googlesource.com 官方仓库的镜像)。本翻译版本将原项目 README 汉化,方便中文开发者快速了解项目定位、安装方式与参与贡献的途径。

## ✨ 主要特性

- 开源编程语言,专注于让构建简单、可靠、高效的软件变得容易
- 提供官方二进制发行版,覆盖多种操作系统与架构组合
- 支持从源码编译安装,满足定制化环境需求
- 由数千名贡献者共同维护,社区成熟活跃
- 采用 BSD 风格开源许可证,商业与非商业使用友好
- 拥有完善的官方文档、贡献指南与提问渠道

## 🚀 快速开始

1. 访问官方下载页 https://go.dev/dl/ ,根据操作系统和架构下载对应的官方二进制发行版。
2. 下载完成后,按照 https://go.dev/doc/install 的安装说明完成安装。
3. 若你的系统组合没有可用的二进制发行版,可参考 https://go.dev/doc/install/source 的说明从源码编译安装。
4. 安装完成后,运行 `go version` 验证安装是否成功。
5. 如需参与贡献,请先阅读贡献指南:https://go.dev/doc/contribute 。
6. 注意:Go 项目的问题跟踪器仅用于缺陷报告和提案;语言使用问题请参考 https://go.dev/wiki/Questions 列出的提问渠道。
